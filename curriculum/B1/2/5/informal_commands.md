
# Lesson 5: Informal "Tú" Commands

**Grammar:**
Informal `tú` commands are used with friends, family, and people you are familiar with. They have different forms for affirmative (do this) and negative (don't do this).

**1. Affirmative `Tú` Commands**

This is the easy one! For most verbs, the affirmative `tú` command is the same as the **él/ella/usted form of the present indicative**.

*   hablar -> **¡Habla!** (Speak!)
*   comer -> **¡Come!** (Eat!)
*   escribir -> **¡Escribe!** (Write!)

There are only **8 irregular** affirmative `tú` commands. A common mnemonic is:
"**Vin Diesel has ten weapons, eh?**"
(ven, di, sal, haz, ten, ve, pon, sé)

| Verb | Command |
| :--- | :---: |
| venir | **ven** |
| decir | **di** |
| salir | **sal** |
| hacer | **haz** |
| tener | **ten** |
| ir | **ve** |
| poner | **pon** |
| ser | **sé** |

**2. Negative `Tú` Commands**

This is also easy because you already know it! The negative `tú` command uses the **tú form of the present subjunctive**.

*   hablar -> **no hables**
*   comer -> **no comas**
*   escribir -> **no escribas**
*   tener -> **no tengas**
*   ir -> **no vayas**

**Pronoun Placement:**
The rule is the same as for formal commands.
*   **Affirmative:** Attach to the end.
    *   **¡Dímelo!** (Tell me it!)
    *   **¡Ponte** el abrigo! (Put on the coat!)
*   **Negative:** Before the verb.
    *   **No me lo digas.** (Don't tell me it.)
    *   **No te pongas** el abrigo. (Don't put on the coat.)
