
# Lesson 4: Formal Commands (Usted/Ustedes)

**Grammar:**
Commands are used to tell someone what to do. Formal commands are used with people you would address as `usted` (Ud.) or `ustedes` (Uds.).

The good news is that you already know how to form them! Formal commands use the **exact same form as the present subjunctive** for `usted` and `ustedes`.

**Formation Review:**
1.  Start with the `yo` form of the present indicative (`hablo`, `tengo`, `conozco`).
2.  Drop the `-o`.
3.  Add the opposite endings: `-e` for `-ar` verbs, `-a` for `-er`/`-ir` verbs for the `Ud.` command. Add `-en` or `-an` for the `Uds.` command.

| Verb | `yo` form | Usted Command | Ustedes Command |
| :--- | :---: | :---: | :---: |
| hablar | hablo | habl**e** | habl**en** |
| comer | como | com**a** | com**an** |
| escribir | escribo | escrib**a** | escrib**an** |
| tener | tengo | teng**a** | teng**an** |
| decir | digo | dig**a** | dig**an** |
| ser | soy | se**a** | se**an** |
| ir | voy | vay**a** | vay**an** |

**Negative Commands:**
To make a command negative, simply put **no** before the verb. The verb form does not change.
*   **No hable** tan rápido, por favor. (Don't speak so fast, please.)

**Pronoun Placement:**
*   **Affirmative Commands:** Attach pronouns to the end of the verb. You may need to add an accent to preserve the original stress.
    *   *Dígamelo.* (Tell it to me.)
    *   *Siéntense.* (Sit down.)
*   **Negative Commands:** Place pronouns between "no" and the verb.
    *   *No me lo diga.* (Don't tell it to me.)
    *   *No se sienten.* (Don't sit down.)

Examples:
*   **Abra** la ventana, por favor. (Open the window, please.)
*   **Vengan** conmigo. (Come with me.)
*   **Pásenme** la sal. (Pass me the salt.)
