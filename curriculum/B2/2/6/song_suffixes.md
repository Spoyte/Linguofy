# Canción: "La Magia de los Sufijos" (The Magic of Suffixes)

## Estilo Musical
**Género:** Electro-swing con toques de jazz moderno
**Tempo:** 130 BPM
**Instrumentación:** Trompeta lead, clarinete, piano swing, contrabajo, batería electrónica, scratching sutil
**Duración:** 2 minutos 50 segundos

## Letra

**[Verso 1]**
"-ción" y "-sión" forman nombres
De verbos que conocemos
Educación, construcción, invasión
Así el idioma crecemos

"-ista" para profesiones
Dentista, pianista, artista
"-ero" y "-era" para oficios
Panadero, enfermera, lista

**[Coro]**
Los sufijos son la magia
Que transforma las palabras
De un verbo sale un nombre
De un nombre, mil historias

-mente para adverbios
-oso para cualidades
-ito para pequeñito
Mil posibilidades

**[Verso 2]**
"-oso" y "-osa" dan cualidad
Generoso, peligrosa, hermoso
"-able" e "-ible" posibilidad
Amable, visible, dudoso

"-ito", "-ita" diminutivos
Casita, perrito, florecita
"-ón", "-ona" aumentativos
Casón, grandota, chiquita

**[Verso 3]**
"-mente" del femenino sale
Rápidamente, claramente
Fácilmente, probablemente
Adverbios para la mente

"-ura" hace sustantivos
Dulzura, altura, frescura
"-eza" también los crea
Belleza, tristeza, natura

**[Coro]**
Los sufijos son la magia
Que transforma las palabras
De un verbo sale un nombre
De un nombre, mil historias

-mente para adverbios
-oso para cualidades
-ito para pequeñito
Mil posibilidades

**[Puente]**
"-azo" para golpe fuerte
Martillazo, puñetazo
"-ada" para la acción
Patada, mirada, abrazo

"-ería" para el lugar
Panadería, librería
"-ismo" para ideología
Capitalismo, democracia

**[Verso 4]**
"-ante" y "-ente" participan
Estudiante, presidente
"-ido" para los sonidos
Rugido, latido, silente

Los sufijos construyen
Un mundo de palabras nuevas
Cada terminación cuenta
Una historia que se renueva

**[Outro]**

Cada palabra derivada

## Notas Pedagógicas
Esta canción enseña la formación de palabras mediante sufijos en español, cubriendo los más productivos: -ción/-sión (nominalización), -ista/-ero/-era (profesiones), -oso/-osa (cualidades), -mente (adverbios), -ito/-ita (diminutivos), -ón/-ona (aumentativos), -able/-ible (posibilidad), -ura/-eza (cualidades abstractas), etc. Se enfatiza cómo los sufijos transforman palabras base en nuevas categorías gramaticales.
