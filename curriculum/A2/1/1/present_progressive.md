
# Lesson 1: Present Progressive

**New Words:**
*   hablando - speaking
*   comiendo - eating
*   viviendo - living
*   leyendo - reading (irregular gerund)
*   durmiendo - sleeping (irregular gerund)
*   ahora - now
*   ahora mismo - right now

**Grammar:**
The present progressive tense describes an action that is happening *right now*. It is formed with the present tense of **estar** + a **present participle** (also called a gerund).

To form the present participle:
*   For **-ar** verbs, drop the ending and add **-ando**. (hablar -> hablando)
*   For **-er** and **-ir** verbs, drop the ending and add **-iendo**. (comer -> comiendo, vivir -> viviendo)

Some verbs have irregular participles (e.g., leer -> leyendo, dormir -> durmiendo).

Examples:
*   Yo **estoy hablando** español. (I am speaking Spanish.)
*   Ella **está comiendo** una manzana. (She is eating an apple.)
*   ¿Qué **estás haciendo**? (What are you doing?) - *haciendo (doing) is irregular.*
