
# Section 1: Describing Actions

Welcome to A2! In this section, you'll learn how to talk about actions in more sophisticated ways. We'll start with how to describe what is happening *right now*, then move on to replacing nouns with pronouns to make your sentences flow better. Finally, you'll learn a crucial past tense for talking about completed actions.

**Lessons in this section:**

*   **Lesson 1: Present Progressive:** Learn how to form the "-ing" tense to say what you are doing.
*   **Lesson 2: Direct Object Pronouns:** Learn to replace "it," "him," "her," and "them" to avoid repetition.
*   **Lesson 3: Indirect Object Pronouns:** Learn to use the pronouns for "to me," "for you," etc.
*   **Lesson 4: Preterite Tense (Regular Verbs):** Learn how to talk about what happened in the past using regular verbs.
*   **Lesson 5: Preterite Tense (Irregulars):** Master the past tense forms of the most common irregular verbs like `ser`, `ir`, `dar`, and `ver`.
