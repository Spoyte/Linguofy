# Canción: "Se Dice, Se Vende"

**Título:** Se Dice, Se Vende (It's Said, It's Sold)

**Estilo:** Bossa nova suave con guitarra nylon, piano jazz y percusión ligera, sofisticado pero accesible

**Duración:** 2 minutos 45 segundos

## Letra:

**(Verso 1)**
¿Cómo se dice "hello" en español?
Se dice "hola", ¡qué fácil es!
¿Dónde se come bien por aquí?
Se come bien en aquel café.

**(Coro)**
Se dice, se come, se vive,
El se impersonal,
Para hablar en general,
¡Qué útil es hablar así!

Se vende casa nueva,
Se buscan programadores,
¡El se pasivo explica
Qué se hace sin decir quién!

**(Verso 2)**
En España se cena muy tarde,
En México se habla español,
Se necesita más paciencia,
¡Se aprende mejor con amor!

**(Coro)**
Se dice, se come, se vive,
El se impersonal,
Para hablar en general,
¡Qué útil es hablar así!

Se vende casa nueva,
Se buscan programadores,
¡El se pasivo explica
Qué se hace sin decir quién!

**(Puente)**
Singular: se vende, se busca,
Plural: se venden, se buscan,
¡El verbo concuerda
Con lo que se menciona!

Se necesita ayuda,
Se necesitan amigos,
¡La concordancia es clave
Para hablar como nativos!

**(Verso 3)**
¿Cómo se llega al centro?
Se toma el autobús azul,
¿A qué hora se abre la tienda?
Se abre siempre a las doce.

**(Coro Final)**
Se dice muchas cosas,
Se venden muchos sueños,
Se vive la experiencia,
¡Se aprende sin empeño!

Impersonal y pasivo,
Dos usos del se especial,
¡Ya los puedo usar
De forma natural!

## Notas didácticas:
- Demuestra ambos usos del "se" en contextos cotidianos
- La bossa nova da sofisticación sin complicación
- Enfatiza la concordancia en el "se" pasivo
- Los ejemplos son prácticos para situaciones reales
