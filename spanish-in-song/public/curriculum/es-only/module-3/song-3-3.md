#
**Módulo:** 3 – L’Aventure du Voyage
**Estilo Musical:** Pop-flamenco moderno (120 BPM)

## Objetivos de Aprendizaje

- Describir una ciudad y sus monumentos usando **ser** y **estar**
- Expresar emociones: *estoy enamorado, estoy sorprendido*
- Practicar el pretérito perfecto (he llegado, he visto)
- Vocabulario cultural: *flamenco, azulejos, naranjos, feria, casco antiguo*
